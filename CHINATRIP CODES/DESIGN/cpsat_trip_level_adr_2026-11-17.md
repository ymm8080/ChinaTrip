# ADR：全程级 CP-SAT 求解 + 披露变量化（2026-11-17 拍板框架，待选点/求解器重构收敛后实施）

- 背景：`solver.py` 已是 OR-Tools CP-SAT（单日排期：区间变量/开放窗/NoOverlap/铁律 pin），但地盘只到「单日时刻」。选点、必去绑定、跨天分配、编辑重排都在 `agent/plan.py`（32k 行 / 500 函数）的启发式级联里；降级契约规定 CP-SAT 不可行 → 回退 LLM 自修复链——**恰在最难的输入上丢掉确定性与完备性**。2026-11-17 基线排查实证：13/13 轮披露「求解器未收敛，时间已按顺序兜底排列」、同输入绑定漂移、必去双在场。
- 本文件是**实施前拍板记录**：并行会话正在重构选点/求解器区域（plan.py 持续在改），动它必撞车；收敛前只落运行时不变量（已落），收敛后按本框架单开一轮。

## D1 目标架构：模型掌管全程，披露变成量

- **变量**：每个候选 POI × 天 → `presence`（optional bool）+ `day` + `start`（区间变量）；每个必去/心愿条目一个 `requested` 字面量 + 一个 `unplaced_var`（bool）。硬链：`requested ∧ ¬presence → unplaced_var`——**必去静默丢失在模型层不可表示**，只能翻转 `unplaced_var` 落进 unplaced/披露（现 e9b492c 出站闸的运行时版）。
- **硬约束**（现 rules.py 铁律的模型化）：开放窗（含 16:00/15:30 白天入场闸，2026-11-17 晚闸口径：SHOW/夜游/夜市豁免、塔类不豁免）、NoOverlap、城际腿缓冲、pinned 时刻、餐锚、班次接驳链。
- **软约束/目标**（字典序分层，替代手搓代价塔 `_morning_extra_cost/_big_first_cost/...`）：①必去覆盖最大化（按重要度加权）②偏好/多样性/评分（补点排序口径同 2026-11-17 拍板：类别精确>距离>时长>评分）③总车程最小化 ④makespan。
- **松弛阶梯替代 LLM 自修复链**：不可行 → 按 D2 声明顺序逐级放软约束（CP-SAT assumptions 字面量），`sufficient_assumptions_for_infeasibility` 直接产出**不可行证书**（「豫园 16:30 闭园 + 朱家角 15:08 回城」）→ 披露文案由证书生成，LLM 只叙述不修排期。
- **确定性**：固定 `num_workers=1` + 固定搜索种子；同输入同输出（「同输入不同行程」应是红灯测试而非日常）。
- **编辑重排**：改时长/挪天/删卡 → 上一版解作 solution hint 热启动重解，替换 `_ripple_after_duration/_resequence` 手搓顺延梯。

## D2 迁移路径（四段，每段独立可验收）

1. **P0（已落地）**：运行时不变量出站闸——必去三分律审计 e9b492c + 双在场清脏 9630b98 + 契约场景测试（test_plan_contract.py）。任何路径产出的行程都过闸，静默丢失先灭绝。
2. **P1（前置，等并行收敛）**：把「请求 → 候选集 → 排期」抽成显式输入的纯核（request model：musts/wishes/constraints 结构化），LLM 只留意图抽取与叙述；现级联作种子（warm start）。
3. **P2（影子运行）**：全程级 CP-SAT 与现级联并行跑，同输入对比（黄金行程语料做裁判）；只记录不切流。
4. **P3（切流收口）**：切 CP-SAT 主路径，删级联回退分支；「求解器未收敛」披露归零为验收线；P4 编辑热启动重解替手搓顺延。

## D3 验收与回归

- 契约测试全绿（三分律/双在场/双胞胎口径）+ 黄金行程语料（真实事故场景库，持续扩）+ 属性式不变量（同输入逐字节可复现）。
- 性能：每程几十个景点，CP-SAT 亚秒级；现有 3s 预算不动。
- 回滚：P2 影子期无风险；P3 保留级联开关一版。

## D4 风险与坑

- 与并行重构的碰撞窗口：只在 plan.py 选点/求解器区连续 48h 无提交后启动 P1。
- LLM 边界：意图抽取（含 schema 校验+确定性兜底，2026-11-17 已建 wish_fast/_parse_site_answer 先例）与叙述；绝不进放置决策。
- 披露文案由证书生成时注意双语（lang 会话字段）。
- CP-SAT 字面量不可行证书对字典序目标的适配：先跑 assumptions 再分层优化，别混在一次求解里。
