# 近距聚合规则（距离聚合都是近距离聚合优先）

2026-11-08 用户拍板（西安城心簇拆天案），全引擎通用原则，非西安补丁：
**距离聚合都是近距离聚合优先**——近的点先聚成同日，远的点不许抢近簇
的座位。本文是该原则的唯一定义点；各层实现引用本文，不得私设口径。

## 两档半径（真值源 `app/services/itinerary/solver.py`）

| 常量 | 口径 | 语义 |
| --- | --- | --- |
| `TIGHT_CLUSTER_KM = 2.0` | 紧簇（同街区级） | **必须先聚**：紧簇员互相是同日硬偏好 |
| `NEAR_SAMEDAY_KM = 5.0` | 近距同日圈（同片区级） | **可以同日**：圈内连游软偏好；「陌生人」= 与同日其余点位全部出圈 |

两档分立的原因：4.6-5km 压线弱边不得斗过 0.5-2km 强簇（钟楼↔碑林
0.52km 被大雁塔 4.97km 弱边拆散实录，2026-11-08 城心簇案）。

## 不变量（终装审计 `tight_cluster_split_violations`）

紧簇员 v（与某日 D 内点位 ≤2km）被拆到别天，**仅当**以下情形合法：

1. D 未满员（<4 非演出参访）——拆分是认领梯子（tier 序）的合法
   结果，tier 序合法占座不追改（2026-11-08 四拍「东方明珠要的」：
   上海夹具陆家嘴簇日 2/4 空，东方明珠留 day1）；
2. D 满员但无陌生人（与 D 其余点位全部 >5km 的成员）——容量所迫
   （4/日硬闸），拆谁都是拆。

违例 = **D 满员且坐着陌生人，同时紧簇员 v 坐在别天**——坐座顺序错，
陌生人本该把座位让给紧簇员。`_global_resched` 终装点对该不变量做
审计并 `logger.warning` 留痕（2026-10-25 事故后立规：不许静默）；
审计再报 = 某层引入回归。

## 各层接线（改任何一层须保持本表同步）

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 认领（选层） | `plan.py` preclaim：walk-adjacent 前置 + tight_kin 天序 | 紧簇员优先认领紧簇伴所在天 |
| 愈合（选层） | `plan.py` 紧簇愈合同位交换 | 认领后置修复：满员日陌生人换座给紧簇员（**只换座不挪空位**，四拍） |
| 求解 | `solver.py` 贴邻豁免（`_adjacent_big_ids` 等 CP/插入/打磨四路） | 圈内大点对不按「第二个下午大点」判死 |
| 评分 | `scoring.py` afternoon_crowd 同口径豁免 | 违例形态不计罚 |
| 兜底 | `plan.py` 兜底层 `_NEAR_SAMEDAY_KM` 镜像 | 排序/挪日走同圈口径 |
| 审计 | `solver.py tight_cluster_split_violations` + `_global_resched` 终装 | 类级检测兜底，见上 |
