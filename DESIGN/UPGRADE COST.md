## 3. 成本档位（月）

| 方案 | 部署 | 月成本 | 判决 |
|---|---|---|---|
| ① 只跑 GLM-Flash 级小模型 | 1×A10 | 抢占式 7×24 ≈ **¥600–900**；按量 ≈ ¥6–9k；包月 ≈ ¥3.2k | 字面最低成本。质量只够粗筛档，撑不起主力规划 |
| ② 单主力 GLM-4.5-Air | 1×H100（或 2×L20） | 包月 ≈ **¥1.4–1.5 万**；按量 7×24 ≈ ¥5.8–8.6 万 | 自建可用的真正地板价 |
| ③ GLM-4.6 本尊 | 8×H200 | ≈ **¥14 万** | MVP/成长期不碰 |
| ④ 仅开发时段开机（W0 架构演练） | L20 × ~50h/月 | ≈ **¥1,750** | 验证 vLLM+LiteLLM 全链路的最便宜姿势 |
| ⑤ 现行：智谱云 API + 本地 PC 应用服务器 | 0 GPU | ≈ **¥0–100** | 当前生产路径（W1-2 已落地） |

抢占式实例可能被回收 —— 不适合承担带 3 秒响应预算的生产推理，只用于演练/压测/离线任务。

## 4. 打平点（vs 智谱云 API）

- 方案② ¥15,000/月 ≈ 智谱云按 token 消耗 **~1.5 万次完整规划会话**（按 ~¥1/次估）≈ **日均 500 次会话**才追平 —— 比内测量级高 2–3 个数量级。
- 未计入项：运维工时、迁移验证、抢占/冷启动风险（分钟级冷启动违反 3 秒预算）、ECS/带宽/存储。
- 首次架构演练可用个人新用户 ¥300 代金券覆盖（≈30 H100 时，或 ~1000 A10 抢占时）。

## 5. 结论（升级触发条件）

1. **现在**：维持智谱云。适配器模式下切回自建 = 改 `GLM_BASE_URL` + 模型名，一行配置。
2. **需要演练 vLLM+LiteLLM 链路时**：方案④ 按小时开机，单次几十元。
3. **升级自建的触发条件（满足其一）**：
   - 日均数百次完整规划会话（智谱云月账单逼近 ¥1.5 万）；
   - 备案/合规要求模型流量不出域；
   - 出现必须微调的需求（微调算力另计）。
4. 触发后首选方案②（包月单卡 H100 跑 GLM-4.5-Air INT4）；GLM-4.6 本尊规模化后再议。
