# 4A级景区官方基础目录

`4a-official.json` 是多日期官方名录汇编，共 **4,612 条**，在大陆 31 个省级地区均有记录。**安徽、江苏仅部分覆盖；这不是同一时点全国现行完整名录。** 新疆生产建设兵团独立评定名录尚未完成全量核验，港澳台不适用本目录评级体系。

2026-09-11新增独立文件 `4a-updates-official.json`：湖南39条、山西11条、陕西13条、福建4条，共67条正式认定，补齐部分历史时间缺口并包含2026年新增批次。加载器会自动读取两个文件，官方4A原始记录合计4,679条；基础生成器不覆盖增补文件。`rating-corrections.json` 同步新增北京、辽宁、广东8条正式取消/降级，连同原安徽7条共15条。不要把历史记录数当作当前有效景区数量。逐批来源和下载核验信息见增补文件 `coverage_sources`，详细更新说明见项目 `SCENIC_RATINGS.md`。

文化和旅游部说明，4A及以下景区由省级文化和旅游行政部门评定管理。因未取得可读的全国统一官方4A全表，本次从各省文旅主管部门、省级政府，以及安徽部分市县政府的正式名录或认定公告汇总。没有使用百科、商业旅游网站、拟评定公示或协会三免参与名单代替官方评级名录。

- `source_url`：每条记录的官方出处。
- `as_of`：该条名录日期或正式认定日期，只使用 `YYYY-MM-DD` / `YYYY-MM`；官方目录未提供日期时为 `null`。顶层 `as_of` 为 `null`，因为各省日期不同。
- `coverage_sources`：各省来源、计数、日期和限制。其数量是各来源提取数量，增补来源应与基础来源共同理解。
- `missing_provinces`：完全没有取得记录的省级地区；当前为空。
- `partial_provinces`：尚未取得全省完整名录的地区，当前为安徽、江苏。
- `4a-audit.json`：名称和日期检查、与官方正文数目核对、疑似历史4A与现5A同名清单。候选清单不能直接当作身份合并证据。

历史表可能包含之后升级为5A、撤销、改名的景区。当前广西基础表截至2021年底，河南基础表截至2020年底并增补2021–2025年正式认定71家，湖南基础表截至2022年底。其它省份日期见记录。不能仅因为某个名字更接近5A记录就改写其等级。

城市只依据官方表的所在城市或地址中明确的行政区名。原表只有县级归属时保留县名；原表没有可判断的城市则省略 `city`。没有使用地理模型猜测归属。浙江2024表一条原始名称混入“景区名称”列头字样，已参照同一省厅2019目录更正，保留 `original_name`、核验链接和别名。

## 重新生成

生成器是 `dev/build_official_4a.py`，原始官方网址索引是 `4a-sources.json`。`supplements/` 保存逐条核验的正式认定增补和部分省份名录，每条保留来源和原始日期。原始网页、Excel、PDF和中间结果保存在缓存目录，不进入用户数据库，也不提交联系方式等原表字段。

本次使用现有 Codex 文档运行时读取 Excel/PDF，无依赖安装：

```sh
/Users/houguoqing/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 dev/build_official_4a.py --cache-dir /tmp/scenic4a
```

在其它机器使用已经包含 `openpyxl` 和 `pypdf` 的 Python 环境。若缓存缺少原始文件，可增加 `--download-missing`；只有广东旧格式XLS转换需要提供现有LibreOffice：

```sh
python3 dev/build_official_4a.py --download-missing --soffice /path/to/soffice
```

生成器不会安装软件，不会读取环境密钥，不会访问应用数据库。运行前按本机环境要求确认实际Python解释器。

原始网页可能改版或覆盖更新。下载成功不代表取得原来同一版文件，因此更新后应复查来源日期和数量，必要时更新生成器中的日期与计数断言，以及补充文件的具体来源。安徽部分官方旧页只有官方域名搜索索引可读、原URL当前失败，已在其补充文件的 `retrieval_note` 明确说明；这类记录不会伪称为检索日现行目录。
