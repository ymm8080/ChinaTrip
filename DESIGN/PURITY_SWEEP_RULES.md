# 终装日纯度清扫规则（PURITY_SWEEP_RULES）

> 唯一定义点：`CHINATRIP CODES/app/services/agent/plan.py` `_day_purity_sweep`
> （约 5942 行起，交付前单次调用于 validate_plan 之前）。
> 本文档记录设计不变量、错误台账（含实录判例）、已落地修复与遗留未解。
> 修改谓词/排序必须同步回归锚 `tests/test_curated_and_purity.py`（4 个
> sweep 测试）+ 矩阵探针判读法（文末）。

## 1. 起源（2026-11-09 用户四症状，沪→西→沪 days=5 2026-11-16 实测）

1. 兵马俑（tier1，30km 远点）排在 D1 到达日——到达日只应放小点/citywalk/秀。
2. D2 大雁塔+十二时辰簇日被插入钟楼（6.10km）与碑林博物馆。
3. 兵马俑应与《秦俑情》同日（绑好的组合按组合排日；组合太大删次要/
   类型重复项，不拆不塞）。
4. D2 唐宴→钟楼显示步行 2 分钟（真实 5.77km）。

## 2. 清扫器结构（不变量）

```
_day_purity_sweep(plan, protect)
  ① 到达日出圈件清算   远点(>15km 出 medoid 圈)禁到达日
  ② 簇日陌生人两轮清扫 常驻簇收容日挪出弱件(tier≥3)；族占日(≥2 远件)
                        市内异簇占位者回城
  ③ 出圈片区族对齐     族锚=坐族内演出日；散件向锚日合并
  尾闸 _fallback_sequence_times + 无时刻挪动回滚(②③ 挪后无时刻=物理
      排不下 → 回原日 + WARN + 披露)
```

三原则（用户拍板，不可违背）：

- **必去/心愿卡只挪不删**：挪不动=保留+WARN+披露（「已保留在第X天，
  可按需调整」），整跳不许可。
- **绑好的组合按组合排日**：≤5km 捆绑/同站近邻是一个排日程单元；组
  合超出容量 → 删次要/类型重复项（带披露「要加回可指定其他天」），
  不得把成员塞进异簇日。
- **任何失败/降级必留痕**：无静默（10-25 立规）。

## 3. 错误台账（实录判例，按发现序）

### E1 漂泊卡互拉（11-09 首拍）
钟楼/碑林博物馆互距 0.52km，同为 D2 陌生人；旧择日规则"任一 ≤5km
单伴即可"→ 两张漂泊卡在异簇日互相当伴、合流到错簇日。
**修**：`_anchor_rank` 锚定择日——目标日须有 ≥2 近圈内常驻锚，或紧簇
（≤2km）单伴，或小日（锚≤2）单伴；漂泊卡（本次清扫已挪动）互不算锚。

### E2 protect 整跳静默（11-09 二拍）
`_exempt` 含 protect → ①对必去卡整体跳过：兵马俑静默滞留 D1，无日志
无披露（违反留痕立规）。
**修**：① 分 keep 卡路径——先锚定择日挪、再容量兜底挪，全失败=保留
+WARN+披露；永不静默整跳。

### E3 跨城分组盲区（11-09 三拍，用户案真根因）
分组键只按 `day.base_city`：沪→西→沪闭环 D1.base_city=上海而兵马俑
（西安点）落 D1 → 兵马俑独占"上海"组，medoid=自身 → ①③ 对它整组空转。
**修**：分组键 = `base_city ∪ 当日非餐/酒店卡的 city`（去"市"后缀）。

### E4 交付边界腿不重算（症状④根因）
最后一次 `annotate_legs` 在装配早段；其后 8 个结构相位挪卡不重算腿 →
唐宴的腿还是挪卡前对 0.1km 同针街区的 2 分钟快照。
**修**：交付边界（attach_hotel_nights 后、return 前）统一
`annotate_legs(plan)` + `_replay_measured_legs(plan)`。

### E5 紧簇单伴误杀（11-14 判读发现）
≥2 锚闸一刀切后，碑林博物馆归 D3 城墙·碑林景区（1.17km 族力）只剩
这一条合格路被拒。
**修**：紧簇（≤`_TIGHT_CLUSTER_KM`=2km）单伴也算合格锚——0.5km 级
贴邻=族力，大日也收。

### E6 锚的序列不稳定性（11-14 复盘）
鼓楼先被容量相位挪进 D2 → 给同被清算的碑林博当了"常驻锚" → 清扫转
头又把鼓楼挪走 → 碑林博被搁浅在 6km 空簇。
**修**：稳定锚——锚必须是目标日**支配分量成员**（`_dom_core_ids`：非餐
/酒店参访按近距同日圈连通，数量→时长取最大），或 tier<3 / 豁免件
（钉/软钉/curated/餐/宿/演出=清扫挪不动的稳定常驻）。

### E7 圈边锚凭计数压过真族伴（11-14 三拍，**未全解→O1**）
碑林博物馆→大雁塔伞卡 4.99km、→十二时辰街区 4.82km——都压在 5km 圈
边 → near=2 让 D2 合格且按伴数排序排最前；真族伴 城墙碑林 1.17km /
鼓楼 1.10km 反而输。
**修（部分）**：择日排序改为**最近锚距离**升序（就近归簇优先于伴数）。
**未解残尾**：见 O1——三因叠加下碑林博仍落 D2。

### E8 pass 交错误判（11-14 spy 实录，**未解→O2**）
碑林博在 D3 城心三人组（城墙碑林+鼓楼+碑林博）应受 core 保护不被判
陌生人，仍被从 D3 挪出；鼓楼 D2→D3→D4 乒乓。两轮 ② 与相位间以"当
时盘面"为快照，前一步挪动改变后一步的簇判定，无全局一致视图。

## 4. 遗留未解（OPEN）

### O1 11-14 碑林博滞留 D2（圈边+殿后+过滤三因叠加）
spy 实测候选序：`D2(4.82 圈边) → D4(4.99) → D1(1.20 钟楼, 到达日殿后)`。
- **圈边锚**：4.8–5.0km 压线距离在 5km 圈语义里"算近"，但排版价值
  远低于 1–2km 族力。
- **到达日一刀切殿后**：D1 钟楼 1.20km 是碑林博最近的真族伴，但到达
  日策略性殿后使其永不被选；产品口径到达日是"轻量近点为主"而非
  "无点"，90 分钟城心馆完全合法。
- **稳定锚过过滤**：D4 永兴坊距碑林博 2.02km，因 D4 支配分量=兵马俑
  （时长最大单分量）而永兴坊非 core/tier<3/豁免 → 合法 2km 锚被滤掉。
**方案（待落地）**：
1. 锚资格分带：紧簇(≤2km)锚为 A 带，圈边(3.5–5km)锚为 B 带；有 A 带
   候选日时 B 带日不得胜出（排序键 `(arrival, band, best_km)`）。
2. 到达日殿后降档为同带内殿后：当到达日持有 ≤2km 紧簇锚且卡时长
   ≤120min（轻量）时按普通日参与排序。
3. 稳定锚放宽：候选日若存在 ≥2km 圈内锚且该锚非当日陌生人候选本身
   （逐日上下文判定而非全局档位），即可计锚。

### O2 清扫无全局一致视图
两轮 ② 与 ③、楔子、容量相位各自以当时盘面判定，互相改写前提（E6/E8
同根）。**方案**：进入清扫前冻结一份"日→卡"快照，所有锚/核/陌生人
判定读快照；挪动只写真盘并记 journal；轮末统一重算快照再进下一轮。
（等价于组合原子化 Step 1 的前置件。）
