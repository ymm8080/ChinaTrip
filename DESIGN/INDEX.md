## ⚠️ 本项目的核心决策（速查）

1. **国内区先行**：Phase 1 = CN 区（阿里云 + 高德 + CN GPU），海外区 Phase 2；备案链只卡公开上架/收费，不卡开发（v1.6.1）
2. **LLM 分阶段（v1.9.9 反转 v1.6 时序，用户拍板）**：MVP = **智谱云 GLM API**（最小成本：零 capex·按 token·备案走已备案模型简化登记；LiteLLM 路由架构不变）；规模化 = **自部署本地 GLM**（量/成本阈值触发 W11+，v1.6 全本地目标后移实现）；语音/拍照 MVP = 端侧 OS 引擎 + 云 GLM 文本翻译；**不调 Claude/GPT/Qwen 云 API 不变**
3. **LLM 管理解选点，CP-SAT 管可行最优**：排序/排期/餐饮插入走 OR-Tools 求解器，铁律 0–23 硬校验仍是统一关口（v1.8.0）
4. **行动只手off 不代客交易**：预订 = 带参 deeplink 跳渠道（酒店=携程/美团 · 机票=去哪儿/美团 · 火车票=12306 官方），不自建交易不碰资金（铁律 22）；语音+拍照翻译全本地（Qwen3-ASR + CosyVoice3 + 端侧 OCR/GLM-4.5V，音频与图片不出区不落盘，铁律 21）；支付：Android 微信+支付宝双通道 · iOS 数字商品仅 IAP（v1.9.0）；**佣金现金流：T+30 月结 vs 成本实时垫付 → 3–6 个月运营资金缓冲，订阅在前佣金在后（v1.9.2）**；**退改签：所有预订默认可退改 + 退改规则预订前明示（铁律 23，v1.9.4）**
5. **延迟靠分流，不靠堆算力**：请求分类闸门 ≥80% 请求不触达主力模型；重任务异步化 + 完成推送；用户感知看 TTFT（首 token）不看总时长——站在街头只碰快车道（v1.9.1 §6.12）
6. **入境导航五模式（v2.2）**：步行 = 应用内实时导航（高德 Web API 后端代理 + OSM 自绘 + 端侧 TTS 多语播报 + 偏航重排联动）；公交 = 到站提醒；出租/自驾 = deeplink 高德 App（英文版）；火车/飞机 = 行程层赶车提醒 + 误车应急兜底——**不嵌高德 SDK，Key 永不进客户端不变**
7. **转链交易中心（v2.3）**：App 内不下单，做「候选链接选择器」——2–4 渠道比价卡片组 + 服务端深链归因；**排序佣金权重为零**（信任 > 短期佣金）；卡片不显示佣金；默认单个主推可展开（A/B 备选平铺）
8. **行程中心 + 全局 Agent（v2.4）**：Wishlist→Scheduled→Booked 三态单一事实源（trip_items，手动/对话/粘贴同表同管线）；Memory 四层（Trip State/画像/会话/偏好蒸馏——结构化存储永不只存对话历史）；**写表权限分级：行程变更先方案后写表，纯增量直接写+可撤销**；订单回填三层管道（粘贴回填为主/返回询问/联盟同步双源验证；拒绝通知监听与剪贴板嗅探）
9. **MVP 冒烟期自定义账号（v2.4.1）**：用户名+密码多设备单身份（零外部依赖；登录/注册即认领当前设备行程）；OAuth（支付宝/微信）待企业主体落地后启用，认领关系届时迁移至正式身份；匿名设备 ID 路径保留为默认态
