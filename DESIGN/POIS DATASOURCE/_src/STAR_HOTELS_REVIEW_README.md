## 预匹配方法(v2,保守)
- 归一:小写、去标点、「饭店→酒店」统一;宾馆未做归一(靠包含匹配兜住,如 白天鹅宾馆⊂广州白天鹅宾馆)
- 匹配序:全名精确 → 去括号主名 → 双向包含(≥4 字);城市判定用名单 province/city 字段对库内 city 归一包含
- 状态口径:**命中**(全名等,同城)/命中(别名/去括号)/命中(包含待核)/命中(城市待核)/未在库
