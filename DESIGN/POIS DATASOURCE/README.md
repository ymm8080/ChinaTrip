## 审阅建议（按你的产品规则）

- **剔除候选**：5A 中红色/人物类（韶山、花明楼、延安革命纪念地、一大·二大·四大纪念馆、朱德/邓小平故里、百色起义纪念园、六盘山红军长征、共和摇篮、红色沂蒙?等）；国保「近现代重要史迹」234 处大部分属革命史迹；名镇名村中红色类（竹沟镇、七里坪镇、文家市镇、沙洲瑶族村、党代会/起义旧址村等）。
- **街区**：第二批起多为商业街区，外来游客价值分层明显，可按城市重要性挑。
- **遗址公园/名胜区/UNESCO/名镇名村主体**：基本全为古遗址/自然/古村落类，与规则冲突少。
- **门票预定（09）**：非新 POI 源，是 booking 放票任务的数据底座——扩充 10 行已于 2026-10-26 官方直核并合并进代码种子（28 键，tests 13 passed/ruff 绿）；放票规则随官方调整频繁，开票前由 L1 任务实时校验；毛主席纪念堂=红色题材仅 booking 侧保留、POIS 口径默认排除；三星堆/熊猫基地/兵马俑为官方可订（非 official_quota），河南博/科技馆两处官方未注明放票时刻已在 note 标注。
- **国际平台（10）**：用途是「外国游客从哪些国际渠道发现中国 POI」的参照榜；有中国榜单的主力=Mindtrip/Layla（AI 行程逐日条目）、Sygic（城市 Essentials 编辑榜）、Klook/KKday/WAUG（活动热销榜）、JTB/H.I.S./TUI/雄狮/Itaka/Tourtrans（各国客源团型）；Foursquare 消费端城市榜已下线；小红书条目为二手转写（站内反爬），**不代表小红书官方口径**；三份底稿 intl_group1/2/3.md 在 _src 可溯源。
- **短视频/社媒（11）**：无站内直取数据（三平台均登录墙/反爬，本轮子任务 fetch 不可用），全部 B/C 级二手证据：YouTube 看「中国旅行频道+WatchMojo 榜单」，TikTok 看 #ChinaTravel 话题规模时序与网红行程（Khaby Lame 渝津、IShowSpeed 8 城、张家界宝峰湖活动），Instagram 看五份聚合榜账号；订阅数/播放量会波动，引用前需复核。

## 审后落库方式

点名文件（或点名剔除行）→ 既有管线：产品规则过滤 → `import_museum_grades` 扩 grade/source 映射（如 street/scenic/town/village/guobao/unesco）→ 幂等骨架 upsert（m2_ 式稳定键，只补新增不覆盖）→ `backfill_en_columns` 补英文名 → 坐标走回源链/seed 自动地理编码。

预约景点行（09）审后**不建新 source**：直接合并进 `app/services/reservation_seeds.py`（booking 放票任务种子），pois 侧 `reservation_required` 由携程「需预约」标识回源接管。
