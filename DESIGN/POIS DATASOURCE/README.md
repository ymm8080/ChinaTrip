## 审阅建议

1. **街区**：每行=完整地址+街区名（如「北京市东城区王府井商业街区」）；第 2-4 批中有部分街区偏本地化（如美食街/步行街），可按城市或名称剔除。
2. **5A**：含少量红色/主题景区（韶山、延安革命纪念地、八一/一大纪念馆、朱德/邓小平故里、百色起义纪念园、六盘山红军长征等）——按你的规则这些应剔除；废复情况：乔家大院 2019 摘牌 2024 复牌（year=2014/2024）。
3. **考古遗址公园**：全部为古代遗址类，无过滤需求。
4. **演艺演出**：行业无国家级评级，本表=头部驻场演艺策展；「开放时间」语义=当日观演时段，多数有演出季（夏季场/冬季停演），落库后靠 24h stale 刷新跟档期；红色/战争题材已 flag，不静默入库。数据源优先级：**携程 sight 目录+详情（主源）**——城市目录页 `gs.ctrip.com/html5/you/sight/{slug}.html` 直接收录演出条目（西安目录第 7 位=《长恨歌》演出），详情页字段=当日观演时段/门票区间/地址/评分/点评数/建议时长，与现有 `ctrip_hours.py` 解析器完全同构 → ** trip.com（英文名回填 name_en，如 Song of Everlasting Sorrow）→ 大麦/猫眼（场次核对，反爬强仅人工用）→ 演出方官网（档期权威，如 changhenge.com.cn、songcn.com）**。

## 审后落库方式

点名文件（或点名剔除行）→ 我按既有管线执行：产品规则过滤 → `import_museum_grades` 扩 grade 映射（street/fivea→5a 已有/relicpark）→ 幂等骨架 upsert（m2_ 式稳定键）→ `backfill_en_columns` 补英文名 → 坐标由回源链/seed 自动地理编码补齐。

演艺演出行（审后）：grade=大型旅游演艺 → source=`show`（`s_` 稳定键前缀）→ enrich 优先级插 `show`（携程详情先填当日观演时段/门票/地址/评分 → 高德 V5 地理编码 location）。`DESIGN/ctrip_city_slugs.json` 现覆盖 28/43 演出城市（总表 187 slug），缺 15 城（九寨沟/阳朔/新郑/宁乡/平遥/兰州/廊坊/中牟/景洪/西双版纳/珠海/呼和浩特/郑州/酒泉/南平）须 title-verified 逐一补——错 slug 会落到别的城市页（wuhan83→宁波 教训）。
